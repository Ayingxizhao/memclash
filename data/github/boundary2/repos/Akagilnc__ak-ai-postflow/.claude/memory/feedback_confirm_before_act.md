description: Must wait for explicit user confirmation before modifying anything — "有道理" or self-assessment is NOT confirmation

Never treat your own judgment or the user's acknowledgment of a suggestion as confirmation to proceed.
Only an explicit "改" / "好" / "可以开始" / "动手吧" from the user counts as confirmation.

**Why:** In the CLAUDE.md rewrite session, Claude self-assessed "两点都有道理" and immediately started editing — violating the "等确认后再改" rule it had just written. The user caught it twice.

**How to apply:** After proposing a plan or agreeing with a suggestion, always stop and ask "要现在改吗？" or equivalent. Do not proceed until the user explicitly greenlights.
