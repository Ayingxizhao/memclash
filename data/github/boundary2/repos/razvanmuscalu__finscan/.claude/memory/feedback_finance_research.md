**Why:** User is engineer, finance-novice. Wrong/outdated advice in this domain costs real money. User explicitly asked for informed opinions over confident-sounding guesses.

- Cite sources in response
- If research insufficient, say so — don't fill gaps with assumptions
- Still translate findings to plain language (finance-novice rule from feedback_finance_literacy.md)
