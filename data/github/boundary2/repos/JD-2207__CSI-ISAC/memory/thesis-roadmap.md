### TESTED → NULL AT SCALE — channel charting / contrastive spatial loss
The identifiability diagnostic showed the geo-split loc gap (19.9 m geo vs 5.3 m random) is representation-generalization, not capacity/information, so a metric/charting objective (make latent-distance ≈ spatial-distance) was the on-target fix. Implemented as `charting_loss` + `triplet_charting_loss` (`--loc_contrast_weight`, `--loc_contrast_mode`) on the loc-head embedding; A/B via `exp/exp_contrastive_loc.py`. Results: **global distance-matching = null even at 10k**; **batch-hard triplet helped at 10k** (w=3: −2.6 m MAE, −6.8 m p90, consistent across weights) **but did NOT transfer to 100k** (`results/contrastive_loc/100k_triplet/`: control 19.1 m vs w=3 19.5 m MAE — +0.4 m, p50 +0.5, only p90 −2.1). MECHANISM: at 10k the baseline is far from its grid floor so charting has slack; at 100k the MSE regression already learns a strong map from 84k samples (19.1 m, near the 8.1 m grid floor), leaving no median headroom — charting only redistributes (tiny tail gain, tiny median loss). **Conclusion: the geo gap is NOT closeable with an in-model contrastive aux loss at scale → confirms the floor needs NEW INFORMATION (multi-gNB / temporal).** Code retained (opt-in, default off); could revisit with a non-parametric chart readout or codeword-level loss, but not the lever.

### TESTED → NEGATIVE — #1 GPS-free self-aided ISAC
The intended headline (replace FLnet's external GPS prior with our own gated loc estimate, fed back into decoder+loc for a refinement round). BUILT (`--self_aided`) and tested: round-1→round-2 gives +0.0% loc / +0.17 dB recon. The self-derived prior is informationally REDUNDANT with the codeword the heads already read — FLnet's gain needed EXTERNAL info. Defensible negative result; self-aiding only pays with NEW info (temporal prior = Phase 3, or a real external fix). Full writeup in [[self-aided-probabilistic-pareto]].
